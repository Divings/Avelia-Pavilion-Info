INSTALLATION GUIDE

確認してから、適用する。

すでに導入されたWebAdminへパッチを追加するための基本手順です。各パッチ固有の条件は、ZIP内のREADMEを優先して確認してください。

このガイドはWebAdminの追加パッチ用です。製品本体の新規導入手順ではありません。

01

対象環境を確認する

Oracle Linux 9/10のWebAdminと共有ストレージが導入済みであることを確認します。今回の3種はアヴェリア本体のコードを変更しません。

パッチ対象ファイル
PDFプレビューfiles.php / files_api.php / files.js
画像プレビューfiles.php / files_api.php / files.js
ディレクトリ保護既存ファイル管理画面・APIと保護用PHP
02

ZIPを取得して照合する

パッチ一覧からZIPとSHA-256を取得します。サーバーへの転送前後で同じ値になることを確認してください。

sha256sum Avelia_Image_Preview_Patch.zip

Windows PowerShellの場合：

Get-FileHash .\Avelia_Image_Preview_Patch.zip -Algorithm SHA256
03

バックアップと適用前確認

VMスナップショット、または既存WebAdminと関連設定を復元できるバックアップを取ります。パッチ適用にはsudo権限が必要です。差分が一致しなければ、無理に適用せず停止してください。

ディレクトリ保護は適用前のfiles.php / files_api.php / files.jsを対象に差分を確認する構成です。両方を導入する場合の基本順は「ディレクトリ保護Fixed版 → 画像プレビュー」です。逆順の適合性を保証するものではありません。PDFプレビューも導入する場合は、既存構成を確認したうえで最後に適用します。

04

展開したフォルダで実行する

以下は画像プレビューパッチの例です。ダウンロード名とZIP内部のディレクトリ名は異なります。

unzip Avelia_Image_Preview_Patch.zip
cd Avelia_WebAdmin_Image_Preview_Patch
sudo bash install.sh

ディレクトリ保護Fixed版の場合：

unzip Avelia_Folder_Protection_Patch_Fixed.zip
cd Avelia_WebAdmin_Directory_Password_Patch
sudo bash install.sh

インストーラーが表示したバックアップ先と結果を控えてください。既存ファイルが異なる場合や適用済みの場合は停止することがあります。

05

ブラウザーで確認する

ファイル管理画面をCtrl+Shift+Rなどで再読み込みします。画像プレビューは「画像表示」、フォルダ保護は「保護」の操作から、テスト用データで確認します。ログイン前・フォルダ保護解除前のアクセスも確認してください。

不具合があれば作業を続けず、バックアップした構成一式から戻す方法を確認してください。全パッチに共通する自動ロールバックはありません。

運用時の範囲と制約

  • WebAdminの保護はOS・SSH・アヴェリア本体からの直接アクセスを制限しません。
  • HTTP/WS構成のままでは通信は暗号化されません。信頼できるネットワークを前提とし、外部公開時のHTTPSやアクセス制限は別途検討してください。
  • 既存のファイル検査と読み取りの間には、シンボリックリンク差し替えなどの競合リスクが残ります。
  • 保護パスワードを忘れた場合のWeb画面からのリセット機能はありません。詳細は配布READMEを参照してください。
