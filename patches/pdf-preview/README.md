# PDFプレビューパッチ

配布日: 2026-10-28

配布ファイル: Avelia_PDF_Preview_Patch.zip

## 機能・対象

Oracle Linux 9/10の導入済みAvelia Pavilion WebAdminに、PDFファイルの「PDF表示」ボタンを追加します。ブラウザー内蔵PDFビューアで表示し、20 MiB以下で%PDF-ヘッダーを持つファイルを対象とします。アヴェリア本体・Nginx設定は変更しません。

画像プレビューとディレクトリ保護の有無に合わせ、通常／保護／画像／画像＋保護の4構成から差分を選択します。ログイン認証と、導入済みならディレクトリ保護を継承します。

## 適用

事前にVMスナップショットまたは復元可能なバックアップを取ってください。

```sh
unzip Avelia_PDF_Preview_Patch.zip
cd Avelia_WebAdmin_PDF_Preview_Patch
sudo bash install.sh
```

GNU patchがなければ導入する構成です。差分のdry-runと一時コピーのPHP構文確認後、既存ファイルをバックアップして適用します。不一致時は強制適用せず停止してください。詳細はZIP内のREADMEとinstall.shを参照してください。

## 確認状況・制約

2026-10-28、画像プレビュー＋ディレクトリ保護の構成に適用しました。転送時のSHA-256、dry-run、適用前バックアップ、適用後PHP・JavaScript構文、Nginx設定とサービス状態を確認しています。2ページのテストPDFを共有領域へ配置し、利用者より動作確認完了の報告を受けています。その他すべての構成での実機検証を意味しません。

表示やページ操作はブラウザーのPDFビューアに依存します。WebAdmin外のSSH・OS・アヴェリア本体からの直接アクセスは保護しません。既存のパス検査やシンボリックリンク差し替え競合に関する制約は残ります。
